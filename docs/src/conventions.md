# Conventions

Time
: Stored in UTC, labeled in New York time. Each value shows its age.

Quality
: Failed values are flagged with a reason or left as gaps.

Units
: Speed, height and temperature follow the Units switch. Salinity: practical salinity scale, unitless. Dissolved
  oxygen: mg/L. Turbidity: NTU (buoys), FNU (rivers).

Direction
: Wind: direction of origin, true north. Currents and waves: direction of travel.

Scales
: Fixed; a color means one value every day.

Measured and modeled
: Measurements gold; model values in the model's color, labeled as a model.

Plots
: After Tufte ({ref}`2001 <ref-tufte2001visual>`): line work, small multiples on shared axes, sparklines.

Status
: All data are provisional; sources may revise them.
